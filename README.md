# Sub3

A beer-chugging logbook for parties. Create a party, log each attempt with a time and a photo, and see the best results in the Hall of Fame.

This repository holds the first version. The live app at [sub3-nine.vercel.app](https://sub3-nine.vercel.app) has since been rebuilt in a separate codebase.

## Stack

- `client/`: React and Vite
- `server/`: Express API
- Firebase for data, deployed on Vercel
